# 脉冲

模因币量化研究台。扫描 Solana、Base、Ethereum、BSC 上的趋势池，用流动性和成交结构做硬过滤，再按买卖差、动量、深度、换手打分，最后在纸面上按恒定乘积滑点开平仓。也可以对选中的池子跑一段 5 分钟 K 线回测。

不连接钱包，没有私钥，不会发送真实交易。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:4317](http://127.0.0.1:4317)。行情来自 [GeckoTerminal](https://www.geckoterminal.com/) 的公开接口，不需要密钥。接口有频率限制，刷新太密会失败，等十几秒再试。

```bash
npm test
npm run lint
```

纸面账本写在 `data/portfolio.json`，这个目录不会进版本库。

## 程序怎么分层

1. **宇宙**：每条链的趋势池，搜索时改查池子。同一只币只保留流动性最深的池。
2. **硬过滤**：流动性、池龄、报价资产、小时成交笔数、FDV / 流动性、1 小时涨幅区间、买卖差。不过滤就没有开仓资格。默认池龄至少 45 分钟，避免去抢刚开盘的那一下。
3. **分数**：买卖差 28%，动量 30%，流动性 24%，换手 18%。垂直拉升和极端换手不会拿高分。
4. **仓位**：单笔不超过上限，也不超过池子流动性的 1.5%。滑点按「报价储备 ≈ 流动性 / 2」估算，再加上手续费。超过滑点上限就放弃。
5. **出场**：止损、止盈、移动止盈、分数跌破、持有超时。当天回撤达到上限后只出场、不开新仓。每一轮最多新开一只。
6. **回测**：信号在 K 线收盘确认，下一根开盘成交。K 线没有买卖笔数，所以回测进场是动量加放量的近似，不是扫描分数的复刻。滑点用当前流动性代替整段历史，结果会偏乐观。

规则可以在「组合」里改。改完会重新给当前扫描打分。

## 这套东西故意不做的事

- 不签交易、不保管私钥、不接聚合器。
- 不抢区块、不夹子、不对倒、不跟喊单群。
- 不把社媒热度当主信号。
- 不根据公开行情判断合约是不是貔貅。纸面能卖出，不代表链上卖得掉。

真要往实盘走，缺的是独立小额钱包、卖出前的可卖探测、失败重试和比纸面更严的额度，而不是把现在的按钮接上签名。
